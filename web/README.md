## 🚀 Quick Start

\`\`\`bash
# Install dependencies
npm install

# Run development server
npm run dev
\`\`\`

Visit [http://localhost:5173](http://localhost:5173)

## 📁 Project Structure

\`\`\`
web/
├── src/
│   ├── components/

│   ├── pages/

## ✨ Features

- **Modern Stack**: React 18 + Vite + TailwindCSS v3
- **Animations**: Framer Motion for smooth transitions
- **Icons**: Tabler Icons
- **Responsive**: Mobile-first design
- **Dark Mode**: Built-in theme toggle
- **Components**: Reusable UI library

## 🎨 Landing Page Sections

1. **Hero** - AI Governance headline with CTA
2. **Companies** - Trust indicators
3. **Features** - Bento grid layout showcasing capabilities
4. **Testimonials** - Animated marquee
5. **Pricing** - 3-tier pricing model
6. **FAQ** - Collapsible accordions
7. **CTA** - Final call-to-action
8. **Footer** - Links and copyright

## 📦 Dependencies

- **react**: ^18.2.0
- **vite**: ^7.2.5
- **tailwindcss**: ^3.4.15
- **framer-motion**: For animations
- **@tabler/icons-react**: Icon library
